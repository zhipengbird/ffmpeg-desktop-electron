# 媒体工具箱 (Media Toolbox) · 产品文档

> **一站式离线桌面音视频处理工作台**  
> 基于 Electron + FFmpeg + Sharp 构建，开箱即用、完全离线、隐私安全。

---

## 📌 产品定位

**媒体工具箱** 是一款面向 **自媒体创作者、职场办公人员、设计师与开发者** 的现代化轻量桌面媒体处理软件。它将底层复杂的 FFmpeg 命令行与工业级图像处理引擎封装为直观、流畅、零学习成本的图形界面，无需用户安装任何外部依赖，开箱即用。

* **100% 本地离线**：所有转码、压缩、提取操作均在本地机器完成，绝不上传云端，彻底杜绝数据泄露风险。
* **专业级调优**：内置自媒体高频预设（微信/邮箱体积锁定、双遍调色板高清 GIF、现代动画 WebP），兼具傻瓜式操作与极客级参数微调。
* **桌面原生质感**：提供系统 Dock/任务栏聚合进度条、结果卡片原生拖拽导出、专业剪辑快捷键体系。

## 🛠️ 功能模块全景详解

### 1. 🗜️ 音视频压缩 (Compress)
* **画质预设模式 (CRF 恒定质量)**：
  * **高质量**：CRF 18 · medium 预设 · 音频 192 kbps（视觉无损，适合素材归档）；
  * **平衡 (推荐)**：CRF 23 · medium 预设 · 音频 128 kbps（体积减少 50%～70%，画质无明显差异）；
  * **小体积**：CRF 28 · fast 预设 · 音频 96 kbps（极限体积压缩，适合快速预览与分发）。
* **锁定目标大小模式 (Target File Size)**：
  * 内置常用规格快捷按钮：`网页/钉钉 (10 MB)`、`微信 (20 MB)`、`邮箱 (25 MB)`、`平台 (50 MB)` 与自定义输入；
  * 根据视频实际时长自动计算码率，留有 5% 封装协议开销缓冲，稳定可靠。
* **硬件加速加速引擎**：
  * 支持 macOS VideoToolbox、Windows NVENC/QSV/AMF、Linux VAAPI；
  * 编码异常自动平滑降级至 CPU 软件编码（libx264），确保任务绝不中断。

### 2. 🔄 格式转换与动图制作 (Convert)
* **主流通用格式互转**：
  * **视频**：MP4 (H.264+AAC)、MKV、WebM (VP9+Opus)；
  * **音频**：MP3、AAC、WAV (PCM 16位无损)。
* **🎞️ 高清调色板 GIF 动图**：
  * 采用 `palettegen + paletteuse` 动态提取全局最佳 256 色调色板 + Bayer 差分抖动，画质细腻无噪点。
* **🚀 现代动画 WebP (Animated WebP)**：
  * 原生支持 1670 万真彩色，文件体积比 GIF 小 30%～50%，支持自媒体与前端开发。
  * 可自由配置动图帧率（`10 / 15 / 24 fps`）及缩放宽度（`320px / 480px / 640px / 原始尺寸`）。

### 3. ✂️ 视频预览与精准裁剪 (Trim)
* **流式极速分块加载**：基于自定义 `media://` Range 协议，GB 级别大视频瞬间打开并拖动跳转。
* **专业级时间轴滑块**：可视化入点（起点）与出点（终点）手柄，支持逐帧对齐。
* **双模导出**：
  * **⚡ 极速模式 (流复制)**：不重新编码，0.1 秒秒级截出，100% 原始画质；
  * **🎯 精准模式 (重编码)**：帧级精确截取，支持硬件加速。
* **全套专业快捷键**：
  * <kbd>Space</kbd>：播放 / 暂停；
  * <kbd>[</kbd> / <kbd>I</kbd>：将当前播放头设为截取起点；
  * <kbd>]</kbd> / <kbd>O</kbd>：将当前播放头设为截取终点；
  * <kbd>←</kbd> / <kbd>→</kbd>：0.1s 逐帧微调（Shift 加速 1s）；
  * <kbd>Esc</kbd>：分层递进取消（输入框失焦 ➔ 取消任务 ➔ 暂停播放 ➔ 清除结果 ➔ 清空当前文件）。

### 4. 🎵 音视频分离 (Separate)
* **提取音频 (MP3)**：重新编码为高兼容性 MP3 音频文件；
* **零损耗提取原音频 (流复制)**：提取视频内嵌的原生音频流（AAC ➔ .m4a、Opus ➔ .opus、FLAC ➔ .flac），毫秒级提取，音质零损坏；
* **导出无声视频 (流复制)**：剥离音轨，仅保留原画质纯视频流。

### 5. 🧩 多视频拼接与无损合并 (Merge)
* **批量排序合并**：支持任意拖入多个视频片段，自由上移、下移调整播放顺序；
* **双模合流引擎**：
  * **⚡ 极速无损合并 (Stream Copy)**：自动检测多片段流格式，若编码、分辨率与声道一致，采用 FFmpeg `concat demuxer` 秒级合并，0 损画质，0 编解码发热；
  * **🎯 智能规整重编码 (Transcode)**：对于不同分辨率或无声视频，自动统一规整到标准比例（主体居中自适应、黑边填充），补全缺失静音音轨，实现平滑合流；
* **智能音量均衡**：支持多片段音量标准化，消除片段切换间的爆音或音量跳跃。

### 6. 🖼️ 图片批量压缩 (Image)
* **基于 Sharp 高性能 C++ 引擎**（Linux 上具备独立进程沙箱隔离防崩溃与 FFmpeg 双引擎兜底）；
* 支持 JPEG、PNG、WebP，支持“保持原格式批量压缩”；
* PNG 深度调色板量化（8-bit Palette），大幅缩减 UI 切图体积。

### 7. 🛡️ 隐私脱敏与敏感元数据清洗 (Metadata Stripper)
* **全局一键脱敏**：可在设置中开启「擦除敏感元数据」；
* **全面隐私防护**：清除视频、音频及照片中的 GPS 经纬度位置（拍摄住址）、相机手机型号、拍摄/录制时间戳、作者与版权描述；
* 采用 `-map_metadata -1 -map_chapters -1` 与 Sharp EXIF 标签清理，保护个人隐私防泄露。

### 8. 🔍 画质前后分屏左右拉杆对比 (Split Screen Comparison)
* **像素级细节走查**：类似 Google Squoosh，在处理完成结果卡片上可直接呼出「画质对比」；
* **智能关键帧抽取**：极速截取原文件与压缩文件的代表帧画面；
* **交互式滑动分界线**：鼠标左右滑动实时比对文字锐度、暗部噪点与压缩失真度，并提供“滑块分屏”、“仅看原画”、“仅看压缩后”快速切换。

### 9. 🔊 广播级智能音量标准化 (EBU R128 Loudness Normalization)
* 消除自媒体剪辑与音频导出中常见的声音太小、爆音破音或多段音频忽大忽小问题；
* 严格遵循广播级 EBU R128 标准，将响度锁定在 -16 LUFS，最大峰值控制在 -1.5 dB。

### 10. ⚙️ 全局设置与系统整合 (Settings)
* 自定义输出位置（与原文件相同目录 / 集中指定输出目录）；
* 重名处理策略（自动加序号 `(1)` / 跳过已存在 / 覆盖原文件）；
* 完成动作（系统通知弹窗提示、自动打开所在文件夹）；
* 隐私安全（敏感元数据一键彻底擦除）；
* 独立并发数控制（音视频并发 1～8，图片并发 1～16）；
* 硬件加速开关与指定 GPU 设备。

## 💡 产品特色与人机工程细节

1. **原生拖拽导出 (Native Drag Out)**：
   任务完成后，鼠标长按结果卡片或队列项，即可像原生文件一样直接拖拽到桌面、微信、飞书或任意文件管理器中，彻底省去“先点定位再在访达中查找拖拽”的繁琐步骤。
2. **Dock / 任务栏全局进度聚合**：
   无论最小化窗口还是切换到其他软件工作，在 macOS Dock 和 Windows 任务栏上均能实时查看到整体批处理的进度百分比及红绿异常反馈。
3. **中文输入法无缝兼容**：
   快捷键监听底层硬件键码（Physical KeyCode），无论用户当前处于中文拼音状态还是英文状态，均能 100% 稳定响应。
4. **安全写出机制**：
   所有任务均采用“隐藏临时文件写入 ➔ 成功后原子重命名”的机制，中途取消或崩溃时自动清扫残留，绝不产生破坏性的半截损坏文件，更绝不覆盖源文件。
